# `trace_hub`

This package implements the relational compatibility runtime used by current
evaluations and operational scripts. It was previously labeled as archived,
but the codebase still imported it directly; it is therefore active until those
dependencies are deliberately migrated.

Also implemented in `src/trace_memory/`:

- AES-GCM authenticated text encryption with legacy payload read support
- typed entity/binding concepts with confidence and provenance
- refusal-by-default, evidence citations, and deterministic grounding principles

Still isolated here:

- fixed recall-intent taxonomy
- mutable upsert graph as the capture source of truth
- contact/message-specific product scope
- monolithic graph, importer, API, and service implementation

Historical databases remain under this package's ignored `data/` directory.
